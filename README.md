# Сувениры из Дагестана — Telegram Mini App

Витрина магазина **«Сувениры из Дагестана»** (ножи, топоры, кинжалы из топовых сталей,
шашлычные и шеф-наборы; производство в Кизляре, доставка по всей России — СДЭК и Почта России)
в виде Telegram-бота с мини-приложением (Telegram WebApp): каталог, избранное, корзина,
промокоды, оформление заказа, профиль с историей заказов и админ-панель. Онлайн-оплата не
подключена — заказ уходит менеджеру, дальше всё как обычно: связались, подтвердили, отправили.

Все файлы лежат плоско в корне репозитория — ничего распаковывать не нужно,
просто загрузите папку целиком на GitHub.

## Состав репозитория

```
main.py           — Flask-сервер: мини-апп, Telegram-бот (webhook) и API админ-панели
index.html        — интерфейс мини-приложения (18+ гейт, hero, каталог, корзина, заказ)
admin.html        — админ-панель (товары, заказы, вопросы, промокоды)
products.json     — каталог (админка читает и пишет в этот файл)
orders.json       — заказы (создаётся автоматически)
uploads/          — фото товаров, загруженные из админки
brand/            — логотип и графика: sd-logo.svg, sd-avatar.png, sd-banner.png
requirements.txt  — python-зависимости
Procfile          — команда запуска для Render
render.yaml       — опциональный blueprint для Render
```

## Фирменный стиль

| Что | Значение |
| --- | --- |
| Фон | `#0E0A08` (тёмный орех / чёрная сталь), карточки `#1A1310` |
| Основной акцент | гранатово-красный `#C8372D` → `#7E1612` (градиент кнопок, бегущей строки и фильтров) |
| Золото / цены / орнамент | латунь `#E2B25A` / `#EBC070` |
| Текст | кремовый `#F6ECDD`, вторичный `#B8A692` |
| Статусы | «В наличии» — оливковый `#9CC27A` |
| Заголовки и кнопки | Playfair Display 700–900 (капсом), название и акцентные блоки — Ruslan Display |
| Текст интерфейса | Inter |
| Элементы | эмблема с кинжалом на фоне гор и дагестанским орнаментом, бегущая строка, бейджи-«наклейки» |

Цвета и шрифты задаются переменными в начале `<style>` в `index.html` и `admin.html`
(`:root{ --accent-color … }`) — меняются в одном месте. Шрифты подгружаются с Google Fonts.

### Логотип

`brand/sd-logo.svg` — круглая эмблема (кинжал, горы, солнце, золотой орнамент), векторная.
В `index.html` и `admin.html` она вшита как SVG-спрайт (`#sd-logo`), так что работает
без отдельных запросов. `brand/sd-avatar.png` (512×512) — для аватарки бота и канала,
`brand/sd-banner.png` (1280×640) — для обложки/превью.

## 1. Создайте бота

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`, задайте имя (например, «Сувениры из Дагестана») и username.
2. Сохраните выданный **токен** (`BOT_TOKEN`).
3. `/setuserpic` → загрузите `brand/sd-avatar.png`.

## 2. Загрузите код на GitHub

Создайте репозиторий и загрузите все файлы из этой папки в корень.

## 3. Разверните на Render

1. [render.com](https://render.com) → **New → Web Service**, подключите репозиторий.
2. Сборка определится по `Procfile`, либо вручную:
   - **Build command:** `pip install -r requirements.txt`
   - **Start command:** `gunicorn main:app --bind 0.0.0.0:$PORT`
3. Переменные окружения (**Environment**):
   - `BOT_TOKEN` — токен из BotFather
   - `ADMIN_PASSWORD` — пароль для входа в админ-панель
   - `ADMIN_CHAT_ID` — ваш Telegram ID (узнать: [@userinfobot](https://t.me/userinfobot)); можно несколько через запятую: `111111,222222`. Эти аккаунты получают уведомления о заказах и кнопку «Панель администратора» в `/start`
   - `SHOP_CONTACT` — Telegram-аккаунт менеджера без `@` (по умолчанию `souvenir_dagestan`); на него ведут кнопки «Написать менеджеру»
   - `WEBHOOK_URL` — необязательно; Render сам передаёт `RENDER_EXTERNAL_URL`
4. После первого старта вебхук Telegram устанавливается автоматически.

## 4. Проверьте бота

`/start` → «🗡 Открыть каталог». Первым делом покажется экран «Тебе есть 18?» — после
подтверждения откроется каталог. Добавьте товар в корзину и оформите заказ: покупателю
придёт подтверждение (номер вида `SD-12`), администраторам — уведомление.

## 5. Админ-панель

`https://ваш-адрес.onrender.com/admin` (или кнопка в боте для администратора).

- **Товары** — название, категория (например: Ножи / Топоры / Кинжалы / Шашлычные наборы / Шеф-наборы), цена,
  старая цена, бейдж (Хит / В тренде / Скидка / В наличии), **варианты** (сталь, рукоять, комплектация) через запятую,
  описание, несколько фото. Без фото показывается цветная плашка с кинжалом (6 оттенков).
- **Заказы** — состав, сумма, контакты, статусы (Новый / Связались / Выполнен / Отменён),
  сообщения покупателю прямо из карточки заказа.
- **Вопросы** — вопросы покупателей по товарам и ответы в Telegram.
- **Промокоды** — процент или фиксированная сумма, мин. сумма заказа, лимит использований.

`products.json` содержит **примерный** стартовый каталог из 8 позиций (кинжал, охотничий,
тактический и кухонный ножи, топоры, шашлычный и шеф-наборы). Названия, цены, варианты и
описания — заглушки: замените их реальными и добавьте фото через `/admin`.

## Что в редизайне

- полностью новый визуальный стиль, логотип, палитра и шрифты под магазин «Сувениры из Дагестана»;
- hero «Сталь с характером» с преимуществами магазина (20+ лет, топовые стали, розница и опт,
  доставка по России из Кизляра — СДЭК и Почта России);
- экран подтверждения 18+ при первом входе (запоминается на устройстве) сохранён для ножей,
  топоров и кинжалов; при желании его можно убрать;
- контакты магазина: Telegram `@souvenir_dagestan`, телефон/WhatsApp +7 929 666-05-59;
- все упоминания прежнего магазина удалены; номера заказов — `SD-…`.

## Постоянное хранилище (важно)

На **бесплатном** плане Render диск не сохраняется между рестартами и деплоями —
`products.json`, `orders.json` и `uploads/` пропадут. Для постоянной работы подключите
платный **Persistent Disk** (блок `disk:` в `render.yaml`) с путём монтирования в корень проекта.

Бесплатный инстанс также засыпает без трафика и просыпается несколько секунд на первом запросе.
